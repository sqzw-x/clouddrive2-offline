# CloudDrive2-Offline

> 嗅探磁力 / ed2k 链接并一键添加到 clouddrive2 离线下载

## 安装

[GitHub Release](https://github.com/sqzw-x/clouddrive2-offline/releases/latest/download/clouddrive2-offline.user.js)

## 功能

- 磁力链接与 ed2k 嗅探: 自动检测页面中的磁力链接、ed2k 链接 (含纯文本形式) 并添加 `离线下载` 按钮
- 设置面板: 通过油猴菜单 `CloudDrive2 设置` 打开, 不再向页面注入悬浮按钮
- 离线任务管理: 支持查看离线任务状态, 删除离线任务 (与 CloudDrive2 内置管理器相似)
- 批量添加离线任务: 类似 CloudDrive2 批量添加功能
